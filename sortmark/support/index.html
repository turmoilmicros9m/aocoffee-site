Sortmark Support

What Sortmark is

Sortmark is a Safari extension for macOS that saves web pages with one click and files each one in a folder. It uses built-in sorting rules on your Mac. Optionally, you can add your own AI provider key for pages the rules are unsure about. Sortmark has no account and no developer servers; optional iCloud sync uses your own iCloud account. Requires macOS 14 or later.

Turn Sortmark on in Safari

  1. Open the Sortmark app and click "Open Safari Extensions Settings…". You can also open Safari, then Safari > Settings > Extensions.
  2. Tick the box next to Sortmark.
  3. Allow it on websites: in the Sortmark pane click "Edit Websites...", then choose "Allow" for the sites you want, or set "When visiting other websites" to "Allow" for all of them. You can also click the Sortmark toolbar button on a page and choose an option in Safari's permission prompt.
  4. If the Sortmark button is not in the toolbar, choose View > Customize Toolbar in Safari and drag it in.

Using Sortmark

  • Click the toolbar button to save the current page. A small note appears on the page showing which folder it went to, with "Change folder" and "Remove".
  • Double-click the button, or press Option-Shift-S, to open the folder picker. Type a few letters of a folder and press Return. Sortmark remembers your choice for that site.
  • Right-click the button for "Change folder for this page…", "View all bookmarks" (the dashboard) and "Sortmark settings".
  • Help > Sortmark Help in the Sortmark app opens this page. The app window and Settings > About also link to the Privacy Policy and Support pages, and show the version ("Sortmark 1.0.0").

Frequently asked questions

Where is my data?
On your Mac only, in Safari's storage for the Sortmark extension: bookmarks, folders, learned sites, settings and (unless you turn off "Save page thumbnails" in Settings > Data) page thumbnails. No thumbnails are taken in private windows. Nothing is sent to the developer.

How do I delete it?
Open "Sortmark settings" (right-click the toolbar button), go to Data, and click "Delete all data…", then confirm "Delete all data" in the dialog "Delete all Sortmark data?". This removes bookmarks, thumbnails, learned sites, folders, settings and API keys. You can also use "Delete thumbnails…" (Data), "Forget all…" (Learned sites) or delete individual bookmarks separately. Removing the app and extension also removes the stored data. Back up first with the JSON export if you want a copy.

Does Smart sorting cost money or need an account?
Smart sorting needs your own API key from Anthropic (Claude), OpenAI (GPT), Google (Gemini) or xAI (Grok). Sortmark does not provide one, and the provider may charge you for use. Sortmark works fully without it. It is off until you save a key, turn on the switch "Send page details to Anthropic to pick a folder" (it names the provider you selected: Anthropic, OpenAI, Google or xAI) in Settings > Smart sorting (AI), and click "Allow" in the dialog "Allow Anthropic to receive page details?" ("Not now" leaves it off). Settings shows exactly what is sent under "What Sortmark sends". Then, for uncertain pages, Sortmark sends the page address without its query string, title, site name, description, headings, about the first 600 words of text and your folder names from Safari directly to that provider. Remove the key or turn Smart sorting off to stop. See the privacy policy for details: https://aocoffee.com/sortmark/privacy/.

Why didn't a page save?
Sortmark cannot run on some pages: Safari's start page, settings and extension pages, new tab pages, and other restricted pages. It also cannot read a site you have not allowed it on. Check Safari > Settings > Extensions > Sortmark > Edit Websites... and set the site to "Allow". Then reload the page and try again.

The shortcuts do not work, or open the wrong thing.
Sortmark suggests Shift-Command-S (save) and Shift-Command-L (dashboard). Safari already uses those keys in its own menus, so they collide. Reassign them under Safari > Settings > Extensions, select Sortmark, and set shortcuts you like. Option-Shift-S (change folder) normally has no conflict.

Does it sync between my devices?
Yes, in Safari, if you turn it on: Settings > Data > Sync with iCloud, on each Mac, iPhone and iPad (signed in to the same Apple Account). Bookmarks, folders and learned sites sync; screenshots, API keys and settings stay on each device. Bookmarks already on a device and in iCloud are merged. To remove the iCloud copy, use "Delete Sortmark's iCloud data…" in the same place. Chrome can't sync with Safari; use "Export backup (JSON)" and import it instead.

Does it change Safari's own bookmarks?
No. Sortmark keeps its own list.
